    • Description

    This is a project for my ESP32 to control two SG90 servo motors connected to a laser pointer.

    It can be wirelessly controlled through Bluetooth using an XBox controller, in addition to autonomously "animating" various functions.

    It currently uses a laser pointer from Amazon, held by a 3D print like a microphone clip.

    Psuedocode

    The program is built around the controllerMode() function, which allows the XBox controller decide what mode to be in.

    int modes = 5;
char* mode_arr[] = {"Direct Control", "Autonomous Circle", "Autonomous Polar Circle", "8", "Cardiod"};
void controllerMode() {
  if (x_button) { // Change mode if X button is pressed
    if ((mode < modes-1) && (mode >= 0)) mode++;
    else mode = 0;
    t = 0;
    Serial.print("Mode ");
    Serial.print(mode);
    Serial.print(": ");
    Serial.println(mode_arr[mode]);
    delay(2000);
  }

  switch (mode) {
    case 0: // Direct mapping of joystick positions (x, y) to laser angle (yaw, pitch)
      directControl();
      break;
    case 1: // Circle drawn with Cartesian coordinates
      drawCircle();
      break;
    case 2: // Circle drawn with polar equation
      drawPolarCircle();
      break;
    case 3: // 8 drawn with polar coordinates
      draw8();
      break;
    case 4: // Cardiod drawn with polar coordinates
      drawCardiod();
      break;
  }

  if (BP32.update()) processControllers();

    Conclusion / Future Plans

    I want to make a function that uses a controller joystick (OR iterate on the pointer's previous coordinates) to "shift" the pointer's coordinates. I am fairly certain this will require a rewrite of the Servo.h header file (or at least its functions) for more precise control, to move the laser pointer slowly and accurately.

    I also need to make an algorithm to translate between (x,y) coordinates to (yaw,pitch) coordinates to have a non-curved display on the floor. I believe that some linear algebra will do so but that will be adequate.

    My next iteration of this will be an "initial product launch", that can be recreated by / shipped to customers with instructional videos included. I plan on then shipping out test kits to friends and family. This product will include:

    • New step() method
    • New functions (cardioid, petal pattern (arbitrary amount of petals), etc.)
    • A laser diode controlled by the microcontroller
    • Website to update the function of the robot (alternative to the controller)
    • This should include a "schedule" capability to turn on the laser pointer at certain times (i.e. occupy the cats at the break of dawn so they don't wake me up :) )
    • Redesigned 3D Models to be a sleeker "product"

    After all that, I plan on integrating a camera and Real-Time Object Recognition software to identify cats and their behavior. Then develop a reinforcement model to autonomously "run away/tease" the cats exactly how they like.
